          **TopNavigation** — верхняя панель продукта с навигацией и пользовательскими действиями

          **TopNavigation** размещайте в верхней части интерфейса продукта, когда пользователю нужно видеть его идентичность, глобальные разделы и постоянные действия аккаунта. Центральную область используйте для ключевой навигации или выбора рабочего контекста, а правую — для статусов и пользовательских действий.

          Сохраняйте панель компактной: показывайте только действия, доступные из большинства разделов продукта. Контекстные операции конкретной страницы размещайте в её заголовке, панели инструментов или содержимом, чтобы верхняя навигация оставалась предсказуемой."
      />

    </Tabs.TabPane>

    <Tabs.TabPane tab="Структура" key="composition">

      <DocExampleBlock
        description="**TopNavigation** объединяет логотип и название продукта, центральную область навигации и действия пользователя справа. Основные настройки: **logo**, **title**, **elementCentered**, **contentRight**, **notificationButtonProps**, **notificationIndicator**, **accountMenuProps** и **titleLinkURL**."
      />

      <DocExampleBlock
        title="logo и title"
        description="Обязательные пропы. **logo** задаёт элемент с логотипом, а **title** — название продукта рядом с ним. Название отображается как ссылка."
        code={`
          <TopNavigation logo={<AppLogo />} title="Kaspersky Next" />
        `}
        scope={{ AppLogo, TopNavigation }}
      />

      <DocExampleBlock
        title="titleLinkURL"
        description="Адрес ссылки для названия продукта. По умолчанию — пустая строка."
        code={`
          <TopNavigation
            logo={<AppLogo />}
            title="Kaspersky Next"
            titleLinkURL="#/home"
          />
        `}
        scope={{ AppLogo, TopNavigation }}
      />

      <DocExampleBlock
        title="elementCentered"
        description="Конфигурация центральной области. Поддерживает кнопку с выпадающим меню или горизонтальную навигацию; при отсутствии конфигурации центральная область пуста."
        code={`
          <TopNavigation
            logo={<AppLogo />}
            title="Kaspersky Next"
            elementCentered={{
              type: 'horizontalNavigation',
              horizontalNavigationConfig: {
                items: [
                  { key: 'workspaces', label: 'Workspaces', selected: true },
                  { key: 'licenses', label: 'Licenses' },
                ],
              },
            }}
          />
        `}
        scope={{ AppLogo, TopNavigation }}
      />

      <DocExampleBlock
        title="contentRight"
        description="Произвольный элемент перед кнопкой уведомлений и меню аккаунта в правой части панели."
        code={`
          <TopNavigation
            logo={<AppLogo />}
            title="Kaspersky Next"
            contentRight={<Tag mode="yellow">Getting started: 3 of 12</Tag>}
          />
        `}
        scope={{ AppLogo, Tag, TopNavigation }}
      />

      <DocExampleBlock
        title="notificationButtonProps и notificationIndicator"
        description="**notificationButtonProps** добавляет кнопку уведомлений. **notificationIndicator** показывает на ней индикатор; по умолчанию — `false`."
        code={`
          <TopNavigation
            logo={<AppLogo />}
            title="Kaspersky Next"
            notificationButtonProps={{ onClick: () => alert('Notifications') }}
            notificationIndicator
          />
        `}
        scope={{ AppLogo, TopNavigation }}
      />

      <DocExampleBlock
        title="accountMenuProps"
        description="Настройки меню аккаунта в правой части панели. Меню отображается, только когда передана конфигурация."
        code={`
          <TopNavigation
            logo={<AppLogo />}
            title="Kaspersky Next"
            accountMenuProps={{
              title: 'user@example.com',
              dropdownMenuProps: {
                overlay: [{ children: 'Account settings' }, { children: 'Log out' }],
              },
            }}
          />
        `}
        scope={{ AppLogo, TopNavigation }}
      />

    </Tabs.TabPane>
