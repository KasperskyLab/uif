        description="**Tabs** — горизонтальная навигация между связанными разделами контента на одной странице. Компонент помогает быстро перейти к нужному разделу и сохранить контекст работы. В отличие от **SegmentedControl**, Tabs подходят для самостоятельных разделов с содержимым, а не для переключения между несколькими представлениями одного блока."

      <DocExampleBlock
        title="Когда использовать"

      />

      <DocExampleBlock
        title="Когда не использовать"
        description="Не используйте Tabs для последовательных шагов: вкладки не показывают порядок выполнения и прогресс. Для такого сценария выберите компонент пошаговой навигации. Не размещайте Tabs разных уровней друг за другом: пользователю сложно различить уровни навигации. Если под вкладками нужен второй набор переключателей, используйте **SegmentedControl**."

          Добавляйте информационную иконку рядом с названием вкладки, когда короткой подписи недостаточно для понимания раздела. Иконка открывает тултип с кратким пояснением и не должна повторять название вкладки или скрывать важную информацию.
