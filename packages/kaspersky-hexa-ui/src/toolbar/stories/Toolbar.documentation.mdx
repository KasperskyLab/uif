          **Toolbar** — панель компактных действий и элементов управления для рабочего контекста

          Используйте **Toolbar** над таблицами, списками, рабочими областями и другими контекстами, где пользователю нужны несколько связанных операций: поиск, фильтрация, экспорт и настройка представления. Располагайте в панели действия, относящиеся к содержимому непосредственно под ней, и сохраняйте понятную иерархию между основными и вспомогательными операциями.

          Для одиночного ключевого действия выбирайте **Button**, а для компактного действия рядом с отдельной строкой, карточкой или полем — **Action Button**. Не превращайте панель в единственное место для несвязанных команд: крупные и самостоятельные сценарии лучше выносить в навигацию или отдельный блок интерфейса."

Левая и правая части формируются массивами **left** и **right**; для типовых действий доступны подкомпоненты **Toolbar.Button**, **Toolbar.Search**, **Toolbar.FilterItem**, **Toolbar.ImportItem**, **Toolbar.ExportItem** и другие. Поведение переполнения настраивают **leftLimit** и **autoDropdown**."

      />

      <DocExampleBlock
        title="left и right"
        description="Массивы элементов для левой и правой части панели. В элементах указывают тип: `button`, `dropdown`, `toggleButton`, `link`, `divider` или `children`; у каждого элемента обязателен уникальный **key**. Если **visible**=`false`, элемент не отображается. По умолчанию **left** — пустой массив."
        code={`
          <Toolbar
            left={[
              {
                type: 'button',
                key: 'filter',
                label: 'Фильтры',
                iconBefore: <Placeholder />,
              },
              { type: 'divider', key: 'divider' },
              {
                type: 'dropdown',
                key: 'more',
                label: 'Ещё',
                overlay: [{ children: 'Действие' }],
              },
            ]}
            right={[
              {
                type: 'children',
                key: 'search',
                children: <Toolbar.Search placeholder="Поиск" />,
              },
            ]}
          />
        `}
        scope={{ Placeholder }}
      />

      <DocExampleBlock
        title="leftLimit"

        code={`
          <Toolbar
            leftLimit={2}
            left={[
              { type: 'button', key: 'one', label: 'Один' },
              { type: 'button', key: 'two', label: 'Два' },

          />
        `}

        code={`
          <Toolbar
            autoDropdown
            left={[
              { type: 'button', key: 'one', label: 'Один' },

        code={`
          <Toolbar
            sticky={0}

        code={`

              {

                key: 'view',

              { type: 'link', key: 'help', label: 'Справка', href: '#' },

                type: 'children',
                key: 'search',

        code={`
          <Toolbar
            right={[
              {

        code={`
