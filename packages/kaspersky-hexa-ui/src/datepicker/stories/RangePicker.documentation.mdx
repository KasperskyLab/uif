          **RangePicker** — поле выбора интервала дат «с — по» с календарём, маской ввода и опциональным выбором времени

          **RangePicker** применяют в формах, фильтрах и панелях отчётности, когда пользователю нужно указать период «с — по»: диапазон событий, интервал отчёта, срок действия правила. Единый контрол с двумя полями и общим календарём удобнее двух отдельных полей даты и лучше поддерживает быстрые пресеты периода.

          Для одной конкретной даты используйте **Calendar** (DatePicker). Для интервала только времени без даты — **RangeTimeInput**. Для простого текстового ввода без календаря подойдёт **Textbox**; для выбора из фиксированного списка периодов — **Select** или **SegmentedButton**."

Поддерживает два поля ввода с разделителем, ввод с маской, выпадающий календарь с выделением интервала, очистку значения, **showTime**, **format**, **placeholder**, пресеты **presets**, ограничение дат **disabledDate**, состояния **disabled** и **readonly**, а также **validationStatus**. Для выбора одной даты используйте **Calendar** (раздел DatePicker). Для интервала только времени — **RangeTimeInput**."
