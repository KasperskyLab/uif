          **DatePicker** применяют в формах, фильтрах и панелях настроек, когда пользователю нужно указать конкретную дату или момент времени: период отчёта, срок действия, дату события. Поле сочетается с подписями **Field**, группировкой в **Grid** и сообщениями об ошибке рядом с полем.

          Для интервала «с — по» в макетах используйте **RangePicker**, а не два отдельных **Calendar**, если нужен единый контрол диапазона и пресеты периода. Для интервала только времени — **RangeTimeInput**. Для простого текстового ввода без календаря подойдёт **Textbox**; для выбора из фиксированного списка — **Select** или **SegmentedButton**."
      />

    </Tabs.TabPane>

    <Tabs.TabPane tab="Структура" key="composition">

      <DocExampleBlock
        description="Публичный API выбора даты в Hexa UI — компонент **Calendar** (одна дата). Построен на стилизованном DatePicker из Ant Design и rc-picker с темизацией поля ввода Hexa UI. **Calendar** поддерживает ввод с маской, выпадающий календарь, очистку значения, **showTime**, **format**, **placeholder**, пресеты **presets**, ограничение дат **disabledDate**, состояния **disabled** и **readonly**, а также **validationStatus**. Для диапазонов дат используйте **RangePicker** (отдельный раздел в Storybook). Для интервала времени — **RangeTimeInput**."
      />

      <DocExampleBlock
        title="value"
        description="Контролируемое значение — объект `Date` или `null`, если дата не выбрана. По умолчанию — `null`. Изменения передаются через **onChange**."
        code={`
          <Calendar value={null} />
          <Calendar value={new Date()} />
        `}
      />

      <DocExampleBlock
        title="onChange"
        description="Вызывается после выбора, очистки или ручного ввода даты. Получает новое значение `Date` или `null` и строковое представление даты."
        code={`
          <Calendar
            onChange={(date, dateString) => {
              console.log(date, dateString)
            }}
          />
        `}
      />

      <DocExampleBlock
        title="showTime"
        description="Добавляет панель выбора времени в выпадающем календаре. Доступные значения: `true`, `false`. По умолчанию — `false`. Без выбора времени пользователем при закрытии панели время сбрасывается на полночь."
        code={`
          <Calendar />
          <Calendar showTime />
        `}
      />

      <DocExampleBlock
        title="format"
        description="Формат отображения даты в поле. Строка преобразуется для `date-fns`. Если не задан, используется формат из текущей локали приложения."
        code={`
          <Calendar value={new Date()} />
          <Calendar value={new Date()} format="DD.MM.YYYY" />
        `}
      />

      <DocExampleBlock
        title="placeholder"
        description="Подсказка в пустом поле. Если не задан, подставляется placeholder из локали (зависит от **showTime**)."
        code={`
          <Calendar />
          <Calendar placeholder="Выберите дату" />
        `}
      />

      <DocExampleBlock
        title="presets"
        description="Массив быстрых вариантов в подвале календаря: каждый элемент — **title** (подпись) и **value** (дата). По клику значение применяется и панель закрывается."
        code={`
          <Calendar
            showTime
            presets={[
              { title: 'Сегодня', value: new Date() },
              { title: 'Вчера', value: new Date(Date.now() - 24 * 60 * 60 * 1000) },
            ]}
          />
        `}
      />

      <DocExampleBlock
        title="disabled"
        description="Отключает поле и календарь: ввод и открытие панели недоступны, иконка очистки не показывается. Доступные значения: `true`, `false`. По умолчанию — `false`."
        code={`
          <Calendar disabled />
        `}
      />

      <DocExampleBlock
        title="readonly"
        description="Режим только для чтения: поле ведёт себя как отключённое (**disabled** на уровне picker). Доступные значения: `true`, `false`. По умолчанию — `false`."
        code={`
          <Calendar value={new Date()} />
          <Calendar value={new Date()} readonly />
        `}
      />

      <DocExampleBlock
        title="validationStatus"
        description="Визуальный статус валидации поля ввода. Доступные значения: `default`, `error`, `success`. По умолчанию — `default`."
        code={`
          <Calendar validationStatus="default" />
          <Calendar validationStatus="error" />
          <Calendar validationStatus="success" />
        `}
      />

      <DocExampleBlock
        title="disabledDate"
        description="Функция, возвращающая `true` для дат, недоступных в календаре. Не блокирует ручной ввод в поле — только выбор в панели."
        code={`
          <Calendar disabledDate={(current) => current && current < new Date()} />
        `}
      />

      <DocExampleBlock
        title="disabledTime"
        description="Функция ограничивает доступные значения времени при включённом **showTime**. Используйте её, если пользователю нельзя выбрать отдельные часы, минуты или секунды."
        code={`
          <Calendar
            showTime
            disabledTime={() => ({ disabledHours: () => [0, 1, 2, 3, 4, 5, 6, 7, 8] })}
          />
        `}
      />

      <DocExampleBlock
        title="showNow"
        description="Добавляет в панель выбора времени кнопку перехода к текущему времени. Работает при **showTime**. Доступные значения: `true`, `false`."
        code={`
          <Calendar showTime showNow />
        `}
      />

      <DocExampleBlock
        title="mode"
        description="Задаёт начальный режим панели: `date`, `month`, `year`, `decade` или `week`. Для обычного выбора даты используйте значение по умолчанию — `date`."
        code={`
          <Calendar mode="month" />
        `}
      />

      <DocExampleBlock
        title="allowClear"
        description="Показывает кнопку очистки, когда выбрана дата. Доступные значения: `true`, `false`. По умолчанию — `true`."
        code={`
          <Calendar value={new Date()} />
          <Calendar value={new Date()} allowClear={false} />
        `}
      />

      <DocExampleBlock
        title="open"
        description="Управляет видимостью выпадающего календаря. Доступные значения: `true`, `false`. Используйте вместе с **onOpenChange**, чтобы синхронизировать состояние."
        code={`
          <Calendar open />
        `}
      />

      <DocExampleBlock
        title="onOpenChange"
        description="Вызывается при открытии и закрытии выпадающего календаря. Получает текущее состояние `true` или `false`."
        code={`
          <Calendar onOpenChange={(isOpen) => console.log(isOpen)} />
        `}
      />

      <DocExampleBlock
        title="onPickerClose"
        description="Вызывается, когда пользователь закрывает выпадающий календарь, в том числе после выбора времени."
        code={`
          <Calendar onPickerClose={() => console.log('Календарь закрыт')} />
        `}
      />

      <DocExampleBlock
        title="defaultPickerValue"

        code={`
          <Calendar defaultPickerValue={new Date(2026, 0, 1)} />
        `}
      />

      <DocExampleBlock
        title="onPanelChange"
        description="Вызывается при смене отображаемого периода или режима панели календаря. Получает дату панели и её режим."
        code={`
          <Calendar onPanelChange={(date, mode) => console.log(date, mode)} />
        `}
      />

      <DocExampleBlock

        `}

      <DocExampleBlock
        title="monthCellRender"

        code={`
          <Calendar
            monthCellRender={(current) => <span>{current.getMonth() + 1}</span>}
          />
        `}
      />

      <DocExampleBlock
        title="getPopupContainer"

        code={`
          <Calendar
            getPopupContainer={(trigger) => trigger.parentElement || document.body}
          />
        `}

      <DocExampleBlock
        title="dropdownClassName"

          <Calendar dropdownClassName="custom-calendar-dropdown" />

      <DocExampleBlock

        code={`
          <Calendar inputReadOnly />
        `}
      />
