# Архитектура компонентов

Все компоненты состоят из несколько структурных частей:

`Component` + `Component.styles.scss` + `Types` = `Component`

`Component` является основой компонента, содержит минимальное необходимое количество логики.

`Component Styles` - CSS стили компонента.

`Types` - типизация компонента.

## Пример

```
src
└───button
    │   index.ts
    │   Button.tsx          -> содержит компонент Button
    │   Button.module.scss  -> содержит стили
    │   types.ts            -> содержит типы для компонента (в том числе для пропов)
    └───stories
    │       ...             -> "стори" для сторибука и документация
    └───__tests__
            Button.test.tsx -> модульные тесты
```
