# History Store

Хранит открытые вкладки, выделение, историю изменений и dirty-state.

`editor-store.ts` — store и его фабрика; `store.ts` — экземпляр приложения; `use-editor-store.ts` — React-подписка.

История ограничена 100 операциями на вкладку. Не выполняет файловые запросы; saved snapshot обновляется после подтверждения записи.
