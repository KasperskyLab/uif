# Schema Builder

Создаёт элементы и нормализует схему перед использованием или сохранением.

`serialization.ts` — defaults и нормализация; `create-element.ts` — создание элемента по registry.

Сохраняет пользовательские props и мета без потери пустых массивов. Не выполняет запись и не управляет вкладками.
