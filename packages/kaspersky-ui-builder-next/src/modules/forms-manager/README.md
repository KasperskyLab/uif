# Forms Manager

Управляет списком форм, поиском, созданием, открытием, закрытием, дублированием и сохранением.

`FormsManager.tsx` отображает список; `use-forms-manager.ts` управляет действиями и сообщениями; `catalog.ts` содержит стартовые формы и фабрику новой формы.

Использует Persistence Adapter для файлов и History Store для открытых вкладок.
